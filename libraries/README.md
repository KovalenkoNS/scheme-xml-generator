# Библиотеки

Помещайте в эту папку экспортированные XML-библиотеки SCADA. После добавления или замены файла нажмите в интерфейсе «Обновить библиотеки».

Приложение читает только файлы с расширением `.xml` непосредственно из этой директории.

## Большие vendor-библиотеки

Полная библиотека `all_lb_sinopec.xml` читается напрямую; копировать из неё отдельные `OBJTYPE` или предварительно форматировать файл не требуется. Допустимый размер одного файла — до 512 МиБ.

В старых экспортах могут встречаться C0-символы, которые XML 1.0 запрещает. При чтении приложение потоково заменяет такие байты пробелами, кроме допустимых `TAB`, `LF` и `CR`. Эта нормализация выполняется только в памяти: файл в `libraries/` не изменяется. Для каждой выполненной замены каталог возвращает предупреждение с кодом символа и количеством вхождений.

Остальной документ разбирается строгим XML-декодером. Поэтому повреждённая разметка, незакрытый элемент или другая структурная ошибка по-прежнему приводят к ошибке загрузки, а не маскируются фильтром.

## Совместимость шаблонов

Успешно загруженная библиотека может содержать как совместимые, так и пока не поддерживаемые шаблоны. Каталог показывает:

- общее число найденных шаблонов;
- число шаблонов, совместимых с текущим генератором;
- предупреждения библиотеки;
- состояние и причины несовместимости каждого шаблона.

Для текущего локального `all_lb_sinopec.xml` проверены 377 загруженных шаблонов, из которых 267 помечены совместимыми и проходят smoke-генерацию. Интерфейс получает эти количества из актуального каталога и не хранит их как константы.

Несовместимые шаблоны остаются видимыми для анализа, но не предлагаются для генерации. Добавление нового XML не расширяет набор поддерживаемых `GROBJTYPE` автоматически: применяются общие проверки примитивов, карточек, связей и зависимостей блоков.

Файлы библиотек считаются входными данными. Приложение не перезаписывает и не исправляет их на диске.
