# Проверка просмотра сохранённого XML

Компонент: ES-модули `web/preview/{parser,graphics,navigation,viewer}.js` и `viewer.css`. Вход: импорт `open` из `viewer.js`; зависимости объявлены внутри модулей, порядка глобальных скриптов нет. URL допускается только в same-origin `/api/output/`. Имя заголовка берётся из проверенного URL. Метод возвращает модель либо `null`, ошибку показывает внутри диалога. Браузерный тест использует общий транспорт `tests/support/chromium.cjs`, читает канонические JS/CSS и не копирует их.

```powershell
node --test tests/preview/parser.test.cjs
go run ./tests/preview/fixturegen .artifacts/preview-fixtures
node tests/preview/verify-browser.cjs
```

Node 24 использует встроенный WebSocket; браузер по умолчанию — установленный Chrome, путь можно указать в CHROME_PATH. Fixturegen читает реальный `all_lb_sinopec.xml`, выбирает DIO-1 и выпускает FBD с инверсией, ST и HMI через публичные генераторы. Результаты записываются только в `.artifacts/preview-fixtures`, пользовательский `output/` не меняется. При отсутствии полной библиотеки эта визуальная проверка требует её установки; подмена искусственной схемой не выполняется.

Браузерный тест подаёт сохранённые файлы через локальный `/api/output/`, загружает настоящие production JS/CSS и проверяет POU/кадры, NOT/D32, порты, параметры, масштабирование, мобильный вид, закрытие, строгий XML, DTD, безопасный текст и запрет внешних URL. Последний сценарий меняет только тестовую сохранённую копию и доказывает повторное чтение файла вместо построения из формы. Результаты и PNG сохраняются в `.artifacts/preview-browser/run-*`.

Просмотрщик ограничен 64 МБ на один файл. FBD показывает сохранённые координаты; если генератор расположил NOT далеко от D32, просмотр не исправляет эту геометрию. ST показывается точным STCODE. HMI отображает реальные границы OnePrim и привязки, но не исполняет библиотечные символы, рецепторы, анимацию или SCADA; ограничение видно в диалоге. Это проверка структуры результата, а не импорта или исполнения в целевой SCADA.

Актуальные артефакты: `.artifacts/preview-browser/run-1790681529366-6724/verification.json` и четыре PNG. Ранние тестовые ошибки ожидания числа блоков и сравнения строки с BOM исправлены; production-разбор получает UTF-8 через TextDecoder.
