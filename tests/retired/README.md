# Снятые проверки фиксированного FBD

Статус всех файлов `fixed-fbd/*.go.txt` — **RETIRED, NOT-RUN**. Они не компилируются, не подключаются overlay и не являются второй реализацией генератора. Это снимки тестовых утверждений перед снятием неподдерживаемого поведения, включая выполненные ранее переименования нейтральных контрактов.

Основание: владелец явно разрешил только библиотечный FBD; fixed AO/module-FBD и fallback с nil-профилем удалены из production. Успешный HTTP 410 проверяет запрет маршрута, а не правильность прежней схемы. Эти результаты нельзя выдавать за coverage снятого алгоритма.

| Исторический файл | Что больше не проверяется | Действующая проверка |
|---|---|---|
| ao_mapping_test.go.txt | Встроенная схема AO без библиотеки | Библиотечные FBD в tests/generator/fbd; HTTP отказ AO-FBD |
| dispatch_test.go.txt, io_test.go.txt | Фиксированное дополнение io.modules для AI/AO/DI/DO | Core/HTTP отказ старого формата; каталог и фактические библиотечные шаблоны |
| skz_test.go.txt, skz_di_test.go.txt | Общий fixed-FBD модулей и связей DI | Применимые ST-планы, ID, снимки и 4096 каналов в tests/generator/st |
| skz_do_full_test.go.txt, skz_raw_do_test.go.txt | Фиксированные DO-графы из разреженных таблиц | Полные 32 физических ST-назначения, оба CPU и сверка входов в tests/generator/st |
| skz_native_do_test.go.txt | Встроенные ISA-типы и обязательный NOT для native850 | Обязательный профиль из библиотеки, изменённые ISA ID, независимый переключатель NOT в tests/generator/fbd |
| cpu_physical_checks.go.txt, full_library_physical_checks.go.txt | Снятое физическое дополнение библиотечных POUs | Только библиотечный документ, проверка всех доступных шаблонов, HTTP 410 старого io |
| http_ao_filename.go.txt | Имя файла удалённого AO-FBD helper | Общая действующая политика имён в HTTP output |
| http_unused_assertions.go.txt | Не вызывавшиеся AO/DI/DO fixed-oracles и недостижимая ветка после return | Библиотечные публичные тесты и реальные ST/HTTP сценарии |

Полный текущий запуск — `go test ./... -count=1`. Фактическое число деклараций и результатов записывается новым прогоном; прежние 268 деклараций не являются неизменным критерием полноты. Исходные XML/XLSX-фикстуры сохранены: они могут оставаться независимыми входами/эталонами применимых ST/HMI проверок и не переписываются под текущую реализацию.
