ПРИНЯТАЯ ВНЕШНЯЯ ГРАНИЦА · ADR-0003

SCADA: только экспорт и импорт XML

SCADA — закрытая система за пределами цепочки приложения, orchestrator, сервера и PostgreSQL. Прямой API, SDK, доступ к её БД и автоматические уведомления SCADA не входят в контракт.

Наблюдения записывает человек. Протокол связан с исходным XML, окружением и повторной выгрузкой; это не callback SCADA. Повторный XML показывает выгруженное состояние, но не доказывает выполнение ST/FBD. Функциональные наблюдения фиксируются отдельно.

Кто выполняет файловые действия и как они автоматизируются, ещё не определено. PostgreSQL не отождествляется с БД SCADA; происхождение его данных требует уточнения. Внутренние API и статусы заданий остаются предложением для нашей цепочки.

XLS остаётся существующей функцией. Его роль при границе «только XML» требует ответа Q-SCOPE-005; преобразование XLS в XML или удаление функции не согласованы. Решение ADR-0003 · Оставшиеся вопросы.

Четыре разных смысла слова «ID»
T11ID
Графический блок или примитив. По нему соединяются концы FBD-линий. Генерируется в локальном диапазоне.
CardID / cardId
Ссылка на экземпляр объекта. Владелец и его поля могут иметь одну карточку при разных T11ID.
IsaObjId / ObjMSID
Тип программного блока / вид HMI-мнемосимвола. Это библиотечные зависимости, а не физический адрес.
ModuleID
Реальный аппаратный ID для ST. Вводится пользователем: модулю A1-02 может соответствовать ID 24. Ноль допустим.
OnePOU/@ID, POUNum, GroupID, ControllerID и ResuorceID — ещё отдельные поля. Написание ResuorceID сохранено из нативного XML. Разобрать термины →
