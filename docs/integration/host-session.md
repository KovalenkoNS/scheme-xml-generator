# Соединение с Host

Host передаёт запущенному модулю `HOST_CLIENT_API_URL`, например `http://127.0.0.1:49152`. Генератор читает только `/api/device` этого локального API. Адрес Host-server, пользователь и состояние приходят из оркестратора; отдельная авторизация и подключение PostgreSQL в генераторе отсутствуют.

`GET /api/host/session` генератора возвращает свежий безопасный снимок:

| Поле | Смысл |
|---|---|
| `available` | Получен корректный ответ локального Host |
| `connected` | Host сообщил активное соединение и серверную авторизацию |
| `authenticated`, `reachable` | Отдельные признаки авторизации и доступности Server |
| `server`, `username`, `role` | Текущие значения из Host; имя/роль отсутствуют без авторизации |
| `status`, `message` | Машинный код и краткое сообщение состояния |
| `checkedAt` | Время получения снимка генератором; не время последней сетевой проверки Server |

Статусы: `standalone`, `invalid-host`, `host-unavailable`, `server-unconfigured`, `server-unavailable`, `authentication-required`, `connected`. При ошибке локального Host прежний пользователь и адрес не возвращаются. Технические трассировки, токены и пароли исключены. Совместимое поле `host` в `/api/workspace` использует тот же компонент.

Web-интерфейс запрашивает снимок при открытии, через 3 секунды после предыдущего запроса, при возвращении фокуса/видимости и по кнопке «Обновить». Backend ограничивает HTTP-запрос 2 секундами и ответ 64 KiB; browser отменяет зависший запрос через 4 секунды. Поздние ответы отменённых запросов игнорируются. При ошибке успешный статус снимается, последующие циклы продолжаются.

Host сам проверяет Server в своём фоновом цикле; его сетевой интервал добавляется ко времени обнаружения потери Server. Генератор обновляет уже известное Host состояние, не посылает самостоятельный heartbeat на Server. Перезапуск не требуется при входе, выходе, смене Server или возвращении сети. При полном перезапуске Host с другим локальным портом модуль запускается новым Host заново с актуальным env.

Транспорт допускает HTTP с явным портом и loopback IP без credentials, query, fragment и дополнительного пути. Proxy и redirect отключены для локального обмена. Это переданный оркестратором endpoint, а не настраиваемый адрес Server.

Соединение и готовность IO-контракта — разные признаки. Подключение не означает реализацию получения таблиц/генерации из БД. По уточнению владельца пакет обновляет **соединение**, не данные таблиц и не версии приложений. Основная сохраняет пояснение текущего ограничения; локальная страница работает независимо.

Приёмка соединения по [INT-001 и SDD-003/005](../../.specify/memory/rules.md) выполняется исключительно с полным запущенным окном фактически установленного Host в действующей пользовательской среде, реальным Host-server и подтверждённым подключением к PostgreSQL. Generator скачивается из GitHub и запускается самим Host. Незапущенный необходимый компонент запускается; об отсутствующем сообщается пользователю. Если установленную цепочку проверить невозможно, результат остаётся NOT-RUN; альтернативная среда, подмена звена и прямой доступ модуля к Server/БД запрещены. Перед разрешёнными изменениями состояния сохраняется резервная копия; после сценария данные/настройки восстанавливаются, IO-записи не изменяются.

Прежний Host-runner `tests/delivery/session/` создаёт отдельный профиль и **не используется для текущей приёмки** по Global-01/03. Проверки обнаружения env и модели таймеров также сохраняются как история своих компонентов, а не как альтернативный способ закрыть соединение. Перед итоговым ответом отдельный независимый subagent проверяет все12 пунктов [канонического checklist](../../../../Develop/Host-client/checklist.md); любой незакрытый пункт означает отказ.

Историческая реализация и приёмка: [006](../../specs/006-live-host-session/spec.md), [verification](../../specs/006-live-host-session/verification.md). В запуске30.09.2026 использовались полный Host из `7b1a84a035189fc09f80149e658e4ef1c6c4c04e`, установленный им из GitHub Generator `v2026.09.30` и действующие Server/PostgreSQL; Host `.artifacts/delivered-session/run-XnXjm5/evidence.json` содержит прежние6 PASS. Тогда наблюдались login/logout, смена адреса, отказ и восстановление, ручное обновление и focus; каталог БД читался через Host без изменения строк. Запуск использовал отдельный профиль: его результаты сохраняются исторически и не закрывают нынешнюю приёмку установленного ПО по checklist. Текущий отчёт — [008](../../specs/008-real-io-workbook/verification.md), пока NOT-RUN. Соединение не доказывает реализацию IO mapping, выпуск XML или импорт в SCADA.
