# TASK-0002 · Закрытая SCADA: взаимодействие только через XML

- Дата: 25.09.2026.
- Статус: **Выполнена** — принятое ограничение внесено в документацию.
- Источник: уточнение владельца: «Scada система закрыта, единственный способ взаимодействия с ней — экспорт/импорт .xml файлов».
- Исполнитель: программный агент; источник предметного ограничения — владелец проекта.
- Связанные требования: R-001/R-002, новое R-016; решение ADR-0003.

## Задача и критерии готовности

Зафиксировать принятое ограничение и согласованно обновить постановку, целевую архитектуру, схемы и вопросы. Документация должна явно разделять внутреннюю цепочку app ↔ orchestrator ↔ server ↔ PostgreSQL и внешнюю границу SCADA, доступную только через XML.

Критерии: нет предложения прямого API/SDK/доступа к БД SCADA; экспорт XML отражён как источник доступного контекста; результат генерации не выдаётся за подтверждённый импорт; роль существующего XLS не решена догадкой.

## Известное и границы вывода

- Закрытая SCADA обменивается с внешними участниками только XML-файлами — **ПРИНЯТО**.
- Конкретный исполнитель импорта/экспорта, автоматизация файловых операций, полнота экспортируемых сущностей и проверка результата ещё не определены.
- XML-файловый обмен не устанавливает протоколы между приложением, orchestrator, сервером и PostgreSQL.
- Ранее принятая выгрузка XLS существует в приложении. Её получатель/промежуточная роль при новой границе требуют уточнения Q-SCOPE-005; удаление функции или создание конвертера не запрошено.

3. Согласованы главы [02](../02-current-implementation.md), [04](../04-xml-formats.md), [05](../05-operator-interface-and-xls.md), порядок работы, глоссарий и навигация. Генерация и структурная проверка отделены от внешнего импорта и исполнения.
