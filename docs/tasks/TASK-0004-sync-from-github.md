## Решение и план проверки

1. Сохранить контрольные суммы пользовательских настроек, данных, результатов генерации и библиотек для сравнения после работы.
2. Выполнить `git merge --ff-only origin/main`; не применять принудительное обновление или сброс рабочей копии.
3. Проверить все Go-тесты без кэша, `go vet ./...` и три набора тестов JavaScript (`temporary`, `skz`, `techobjects`). Использовать изолированный временный каталог.
4. При успешных проверках пересобрать единственный основной `XmlSchemeGenerator.exe` с параметрами `build.ps1`, не запуская пользовательское рабочее пространство.
5. Проверить версию, сохранность пользовательских файлов и состояние Git; завершить карточку и обновить журнал задач. Отправка этой локальной записи в GitHub не входит в текущую рабочую трактовку запроса.
