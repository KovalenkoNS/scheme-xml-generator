# TASK-0003 · Текущая версия проекта в Git вместе с документацией

- Статус: **В работе**.
- Дата: 25.09.2026.
- Источник: запрос владельца «Внеси текущую версию на гит, документация не должна быть gitignore».
- Исполнитель: программный агент; публикация текущей версии разрешена запросом владельца.
- Связанные требования: R-003/R-004; ADR-0001.

## Запрос и критерии готовности

Зафиксировать текущие исходники, шаблоны и документацию проекта в Git и отправить в его удалённый репозиторий. Каталог `docs/`, визуальный обзор и правила ведения контекста должны отслеживаться. Существующие исключения для EXE, состояния исполнения, результатов генерации и локальных настроек сохраняются.

Критерии: просмотрен состав коммита; документация включена; исключённые локальные файлы не добавлены; зафиксирован коммит; результат отправки проверен отдельно от локальной фиксации. История удалённой ветки не перезаписывается принудительно.

## Известный контекст

- Проект находится в каталоге, распакованном из `scheme-xml-generator-main.zip`; `.git` отсутствует, Git в PATH и стандартных местах не найден.
- Источник архива указывает на `KovalenkoNS/scheme-xml-generator`, ветку `main`; комментарий ZIP содержит исходный коммит `6d7a93908fff09d51c59b87a1e68754da5348eb8`.
- При первой проверке подключение GitHub не имело доступа к репозиторию (404). После ответа владельца доступ подтверждён чтением метаданных; разрешение записи `push=true`, целевая ветка `main`.
- Существующий `.gitignore` не исключает документацию. Требование владельца будет явно закреплено правилами включения документации и проверено по индексу Git.

## Решение и проверки

1. Использовать переносной Git вне проекта; проверить контрольную сумму официального дистрибутива.
2. Подготовить локальный Git и проверить правила включения документации и исключения рабочих артефактов.
3. Проверить состав и создать локальный коммит текущей версии.
4. Получить удалённую историю, сохранить её при отправке; проверить наличие документации на удалённой ветке. При недоступном репозитории записать конкретный остаток работы, не выдавая локальный коммит за отправленный.

## Выполненная подготовка

- Установлен MinGit 2.55.0.windows.5 в `%LOCALAPPDATA%\Programs\MinGit-2.55.0.5`; исполняемый файл `cmd\git.exe`. SHA256 официального ZIP проверен по метаданным выпуска. Системный PATH не изменялся.
- Инициализирован локальный Git, `origin` указывает на `https://github.com/KovalenkoNS/scheme-xml-generator.git`. Получена история; `origin/main` совпадает с коммитом исходного ZIP `6d7a93908fff09d51c59b87a1e68754da5348eb8`. Локальная `main` продолжает эту историю.
- В `.gitignore` явно включены `docs/**`, AGENTS, README и корневые семантические документы. В `.gitattributes` нативный эталон FBD СКЗ защищён от текстовой нормализации аналогично `XML dev/`.
- Подготовлены исходники и тесты XLS/СКЗ, исправления диагностики и документация текущей версии. EXE, результаты генерации и состояние исполнения сохраняются локально по действующим исключениям.
