# ADR-0002 · Ранее принятые правила генерации

- Статус: **ПРИНЯТО РАНЕЕ**, запись восстановлена из доступных уточнений владельца и сопоставлена с кодом.
- Дата фиксации в этом каталоге: 25.09.2026. Исходные даты каждого уточнения отдельно не зафиксированы.
- Цель: не задавать повторно уже решённые вопросы и не переносить частное правило на неподтверждённый профиль.

| ID правила | Принятое поведение | Область действия / ограничение | Источник |
|---|---|---|---|
| D-001 | Технологические объекты модулей AI/AO/DI/DO и резервы выдаются в одном XLS на ПЛК | Отдельная функция от генерации XML; текущий вход — IO XLSX | Запрос расширения по `_diag.xls` и `_reserves.xls` |
| D-002 | Отдельные резервные объекты создаются только для AI/AO | DI/DO используют каналы D32V | Ответ владельца «отдельные резервы только AI/AO» |
| D-003 | Для типа AN_v1 значение шаблона в XLS — AN | Тип и шаблон не должны механически копировать друг друга | Исправление владельца о AN и шапке XLS |
| D-004 | Шапка XLS повторяет структуру примеров: четыре строки, объединения и оформление | Точный набор полей/масок описан в главе 05 | Пример владельца и исправление реализации |
| D-005 | СКЗ для PLC850 получает отдельную генерацию ST/FBD по новым книгам | Поддержанные текущим парсером направления — AI/DO | Запрос о файлах `examples (1)` |
| D-006 | FBD СКЗ создаёт вызовы объектов AD3_v2/D32V | Не подменяет физическую перекладку ST | Ответ владельца о назначении FBD |
| D-007 | DO ST СКЗ записывает в физический выход значение D32V._NN | Сопоставление с SOGO_DO; исходный Excel использует другой RHS | Ответ владельца «как SOGO_DO: из D32V._NN» |
| D-008 | AI FBD привязывается к тегам Excel; физические входы остаются в ST | Поля владельца и служебные теги описаны профилем; не придумывать дополнительные линии | Уточнение владельца после примеров FBD |
| D-009 | Количество модулей СКЗ пользователь задаёт вручную | Исходные модули сохраняются; дополнительные идут после максимального номера; новые ModuleID вводятся явно | Запрос владельца о ручном количестве |
| D-010 | Каждый модуль AI FBD СКЗ находится в отдельной POU | AI_A1_00, AI_A1_01…; ST и DO сохраняют свои правила группировки | Подтверждённое требование «Исправь это» после обсуждения групп по 16 сигналов |

## Правила, которые нельзя вывести из этих решений

- CPU850 FBD/ST не означает наличие CPU850-профиля HMI или XLS по СКЗ.
- Рабочий тег `_reserve` не означает свободный канал; для СКЗ AI такие теги сохраняются как рабочие резервированные сигналы.
- Общая настройка количества ST/FBD не обновляет уже сохранённые XML-файлы.
- Один модуль AI FBD имеет до 16 исходных каналов; отсутствие строк в существующем модуле не заполняется автоматически. Новые вручную добавленные модули заполнены резервами.
- Одноимённые типы/поля в разных библиотеках не гарантируют одинаковые числовые ID и представления.
- Новые алгоритмы управления, права команд, протокол PostgreSQL и общий выпуск всех форматов этими ответами не определены.

Подробная реализация: [04. FBD/ST](../04-xml-formats.md), [05. HMI/XLS](../05-operator-interface-and-xls.md). Новое изменение этих правил требует записи причины и источника нового решения; прежние ответы не теряются.
