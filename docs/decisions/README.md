Роли приняты в [ADR-0009](ADR-0009-unified-spec-kit.md) и дополнены в [ADR-0010](ADR-0010-host-context-and-plc-domains.md). Обязанности чтения/записи контекста, запросов данных через Host и хранения/маршрутизации IO-листов сервером теперь приняты. Предложенные конкретные сообщения и схема данных из [главы 03](../03-target-architecture.md) остаются предложениями. ADR-0009 заменяет правила размещения новых задач из ADR-0001; принцип первичного документирования сохраняется.

Новое ADR получает следующий номер. Отменённое решение сохраняется со ссылкой на заменяющее; противоречие с текущим кодом отмечается явно.
