# XML Generator для Windows x64

Запустите `XmlSchemeGenerator.exe`. Интерфейс откроется в браузере; Go и Node.js для работы не нужны. Настройки, подключённые библиотеки и результаты сохраняются в каталоге приложения. По умолчанию интерфейс доступен только на этом компьютере, порт 3210.

На основной странице подключите свою XML-библиотеку. Страница «Локальные данные» принимает исходные XLSX и подготовленные TXT-карты: выберите ПЛК, модель 715/850, нужные FBD/ST/HMI и параметры выпуска. FBD использует выбранные шаблоны библиотеки. Физические ModuleID указываются явно.

В результатах нажмите «Просмотр»: FBD показывает сохранённые блоки и связи, ST — сохранённый код, HMI — доступную геометрию кадров. Поиск находит сигнал или блок; «Весь файл» показывает общий обзор. Библиотечные HMI-символы могут отображаться границами без динамики. Просмотр не подтверждает импорт и исполнение в SCADA.

При запуске из Host основная страница показывает его текущее соединение с сервером и пользователя. Состояние обновляется автоматически, при возвращении в окно и по кнопке обновления; повторный вход в генераторе не нужен. При самостоятельном запуске показано отсутствие оркестратора. Получение IO-таблиц через Host → сервер → БД пока не подключено; для генерации доступны локальные источники.

Ограничения подтверждённых профилей: модульный DO FBD с диагностикой — 850; AO ST — 715; DI ST — 850; HMI — 715. AI и DO ST используют выбранный поддержанный профиль адресации. Это ограничения реализации, а не принадлежность ПЛК к РСУ/ПАЗ/СОГО.

Архив поставки содержит EXE и это руководство. Пользовательские библиотеки, таблицы, конфигурация, состояние ID и пароли в поставку не входят. При установке через Host используются GitHub Release и соседний файл `.sha256`.
