# План очистки процесса

Дата: 2026-09-30. Основание: [spec.md](spec.md), [процесс SDD](../../docs/SDD.md), [правила](../../.specify/memory/rules.md).

Применяются SDD-001/002/003/004/005, ARCH-001 и XML-005. Изменение касается только документации; production-код, тесты, XML-источники, сборки и установленное ПО не изменяются. CODE-001/001-T/002/003/004 не получают новой реализации; предметные границы сохраняются.

1. Сохранить точные копии затрагиваемых файлов, исходный статус Git и patch пользовательских изменений вне репозитория, сверить SHA256 (FR-003).
2. Удалить только заменённый шаблон `docs/templates/task.md`; обновить `AGENTS.md`, процесс, конституцию, индексы шаблонов/задач и ссылку в плане перехода 001. Сохранить предметные TASK/ADR и смысловые источники (FR-001).
3. Изменить SDD-005, текущие инструкции, шаблон verification и действующее требование FR-004 пакета 008: reviewer выключен до явного указания пользователя. Зафиксировать источник и дату; прежние наблюдения и незакрытая продуктовая приёмка не меняются (FR-002).
4. Выполнить `node scripts/sdd.cjs check`, `node scripts/check-layout.cjs`, проверку локальных ссылок затронутых документов и `git diff --check`. Поиск обязательных формулировок сопоставить с историческими записями вручную (FR-003).

Адресные статические проверки подтверждают только документационную очистку. Установленный генератор, сервер, БД, runtime-тесты и reviewer не запускаются в этой задаче. Копии до изменения находятся вне Git; координатор формирует коммит только из разрешённых изменений.
