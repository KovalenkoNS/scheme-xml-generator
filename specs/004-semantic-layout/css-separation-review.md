## Владельцы

## Ошибки самого сравнительного сценария

Первый запуск equivalence-1790691884046 завершился exit 1: null.cssRules у отключённого inline style. Следующая попытка equivalence-1790691920830 формально сообщила PASS, но этот результат **отозван**: добавленный отрицательный контроль в equivalence-1790691960605 завершился exit 1 и обнаружил сравнение временно отключённых стилей. Inline style не давал надёжной активной таблицы при CSP; переключение link требует ожидания загрузки. Финальная проверка использует синхронные построенные таблицы с отрицательным контролем, исходные логи не удалены. Это ошибки тестового сценария, не антивирусная блокировка и не повод менять защиту.
