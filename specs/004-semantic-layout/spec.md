# Предметная структура исходников и отдельные тесты

Status: implemented
Date: 2026-09-29.

Приёмка отозвана владельцем 29.09.2026. Подтверждены смешение частных AO/SKZ и общих контрактов, производственных/исторических генераторов, дубли аппаратных правил и тестовых помощников. Ранее отмеченные PASS не являются итоговой приёмкой: [rejection-audit](rejection-audit.md).

Основание: прямое требование владельца разделять ПО по ответственности, хранить все тесты отдельно и объяснять функции содержательными комментариями. Обязательны [.specify/memory/rules.md](../../.specify/memory/rules.md): SDD-001/003, CODE-001/002, ARCH-001, XML-005.

- FR-001: FBD, ST и HMI — отдельные реальные Go-пакеты. Общие контракты, XML-сериализация, адресация, профили и распределение ID не содержат скрытого универсального движка предметной генерации.
- FR-002: HTTP — тонкий транспорт и обработчики по предмету; публичные `appserver.New` и действующие библиотечные/ST/HMI API сохраняют совместимость; фиксированные FBD API исключены по согласованному XML-002.
- FR-003: все версионируемые тесты и их фикстуры находятся под `tests/`. Обычный `go test ./...` исполняет все применимые приватные и внешние проверки без копирования production-кода. Снятые fixed-FBD утверждения хранятся как retired-текст, не считаются выполняемыми или PASS.
- FR-004: функции и методы имеют предметные комментарии о вызове, взаимодействии и результате; проверка правил проверяет реальные исходники и инвентарь каталогов.
- FR-005: перенос не меняет правила генерации, формат XML, исходные библиотеки или образцы пользователя. Структурная проверка не означает успешного импорта в SCADA.
- FR-006: прикладное обозначение SKZ не является универсальной ответственностью ПО. Адаптеры конкретных таблиц, независимая модель назначений, аппаратные профили, планирование и генерация находятся на разных уровнях. Модель и генераторы не импортируют парсеры; столбцы SCS и правила исходных выражений остаются в адаптерах. Переименование файлов без исправления этих зависимостей не выполняет требование (уточнение владельца 29.09.2026).

Уточнение совместимости FR-002/005: по прямому ответу владельца старые HTTP-маршруты FBD со встроенными шаблонами отключаются (410), а FBD доступен только через библиотеку. Исторические XML-проверки не являются разрешением на эти маршруты. Внутренние имена SKZ/FCS заменяются понятиями предметной модели в рамках FR-006; технические URL-алиасы и существующие JSON-имена сохраняются на границе HTTP для совместимости. Совместимые поля wire-формата и синтаксис входных файлов сохраняются. Частные AO/SKZ значения убираются из общих контекстов и метаданных; это исправление неверной зависимости, а не обещание побайтового сохранения отклонённого вывода. Фиксированные внутренние FBD-реализации также удаляются, чтобы запрет не оставлял второй production-алгоритм.

Приёмка: полный Go-набор, пакет веб-проверок (владелец: основная задача), проверка SDD и правил, review границ пакетов. Нарушения обязательных правил оставляют пакет незавершённым.
