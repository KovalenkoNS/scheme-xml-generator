# Пространство имён интерфейса: исправление отклонения

29.09.2026. Связь: T012, FR-002/004/006, CODE-001/002/003. Это доказательства конкретного исправления, а не повторное объявление всей реализации принятой владельцем.

## Фактическая граница

Общие изменяемые `window.GeneratorWorkspace`, `WorkspaceModel` и `GeneratedPreview*` удалены. Файлы UI экспортируют собственные операции и импортируют их фактических владельцев. `index.html` загружает один `shell/bootstrap.js` как ES-модуль; порядок десятков `defer`-скриптов больше не задаёт зависимости.

- `shared/dom` создаёт DOM и не сохраняет предпочтения; `generation/fields` владеет полями настроек выпуска и их сохранением.
- `shared/validation` проверяет числа. Идентификаторы моделей ПЛК принадлежат `equipment/controllers`, контекст ST — `generation/st/context`, имена исходных ПЛК — `sources/model`.
- `shell/state` содержит текущие данные рабочей области, а `shell/preferences` — их запись в localStorage. Статус операции имеет отдельного владельца `shell/status`.
- `generation/results` открывает просмотр через импорт `preview/viewer.open`. Просмотрщик импортирует parser, graphics и navigation, не читая форму генерации.
- Тестовый фасад `web/model.js` удалён: Node-тесты импортируют настоящие предметные модули. Дублирующий транспорт Chromium из preview-теста удалён; все браузерные сценарии используют `tests/support/chromium.cjs`.
- Комментарии файлов описывают конкретные обязанности; сохранение настроек и статуса не прячется под общим DOM-helper. Отдельные комментарии сценариев Node фиксируют проверяемый контракт.
