# План

Правила: SDD-001/003/004, CODE-001/001-T/002/003, ARCH-001, XML-002/005/006.

1. Разделить contracts: `fbd/request` — библиотечный запрос/разрешение; `program` — назначение экспорта; `st/assignment` — планы физических назначений; `identity` — диапазоны и пределы ID; `artifact` — готовый XML и сводка. Модель CPU — `domain/controller`.
2. Перевести imports/типы на единственные определения без aliases; удалить универсальный facade. Перенести подготовку ST-выпуска в ST-сервис; сохранить проверку плана до рендера.
3. appserver получает config.Config и создаёт отдельные FBD/ST/HMI сервисы; workspace получает только Config и отдельно Host client. Согласовать изменения с006, не затронуть transport/session.
4. Проверить отсутствие старых imports и циклов, полный Go-набор и исходные XML-сравнения; актуализировать комментарии и SOURCE_LAYOUT. Реальное дерево войдёт в Host011 карту.

Исходники не копируются для тестов, пользовательские библиотеки/output/state/XML dev не меняются. Изменение API касается internal-пакетов; HTTP JSON остаётся прежним.
