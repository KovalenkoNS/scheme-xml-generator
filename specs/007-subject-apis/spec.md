# Явные владельцы генераторов и контрактов

Status: verified
Date: 2026-09-30

Основание: повторное отклонение владельцем структуры файлов и абстракций30.09. Общий facade.go маскирует зависимости предметных HTTP-компонентов: HMI, FBD, ST и workspace получают универсальный Generator. contracts/types.go смешивает запросы библиотечного FBD, транспортные ID и общий результат; contracts/module_mapping.go содержит частные ST-планы.

- FR-001: FBD/ST/HMI HTTP-сервисы получают только свой генератор; appserver собирает их из конфигурации и allocator. Workspace читает конфигурацию, не зависит от алгоритмов генерации. Универсальный facade и aliases удаляются без второго экземпляра исходников.
- FR-002: библиотечные FBD-запросы, программный контекст, планы ST-назначений, диапазоны ID и готовые XML-результаты имеют отдельных физических владельцев. Общая модель CPU не размещается под алгоритмом генерации. JSON-поля и фактический XML сохраняют совместимость.
- FR-003: проверки обращаются к настоящим владельцам, хранятся отдельно и сохраняют AI/AO/DI/DO, библиотечный FBD, ST/HMI и отказ фиксированного FBD. Комментарии объясняют назначения/данные функций; SOURCE_LAYOUT и файловая web-карта Host соответствуют новому дереву.

Это исправление абстракций, без нового IO-профиля, схемы БД или изменения XML-образцов. Живое соединение принадлежит отдельному [006](../006-live-host-session/spec.md).
