# Публикация проверенной версии и поставка через GitHub

Status: ready
Date: 2026-09-29.

Основание: владелец отклонил результат «гитхаб не исправлен» и явно поручил опубликовать текущие проверенные исходники всех четырёх репозиториев. Этот пакет относится только к XML Generator. Применимы SDD-001/003/004, ARCH-001, HOST-001 и XML-002/005 из [правил](../../.specify/memory/rules.md).

- FR-001: текущие исходники, отдельные тесты, SDD и документация доступны в `KovalenkoNS/scheme-xml-generator` на `main`; удалённый SHA проверен отдельно от локального commit. История сохраняется, force push запрещён.
- FR-002: GitHub Release содержит проверенные `XmlSchemeGenerator-windows-amd64.zip` и соседний `.zip.sha256`. В ZIP только EXE и руководство; пользовательские данные, библиотеки, конфигурация и секреты не публикуются в поставке.
- FR-003: новый пользователь Host получает этот модуль через настоящий GitHub Release в пустой каталог управляемых приложений. Проверяются скачанный SHA256, provenance и запуск установленного EXE; указание текущего локального пути генератора или подмена сети фикстурой не выполняют требование.
- FR-004: результаты удалённой доставки и её ограничения записаны отдельно от локальных тестов. Публикация не доказывает интеграцию IO через Host или импорт XML в SCADA.

US1: пользователь скачивает Host, выбирает стандартный XML Generator и получает готовое приложение без Go, локального репозитория или дополнительных путей.

Связанные изменения исходников и их фактические проверки: [003](../003-unified-workspace/verification.md), [004](../004-semantic-layout/verification.md). Публикация не восстанавливает прежнюю отклонённую приёмку этих пакетов автоматически.
