# Проверка библиотечного DO

Date: 2026-09-29

Повторная проверка: два последних прогона `internal/appserver` (в том числе `-p 1`) завершились FAIL при удалении временного каталога Windows: `directory not empty`. Проверки генерации и HTTP-результатов до cleanup прошли; однако общий прогон не объявляется PASS. Этот сбой требуется устранить и повторно проверить в пакете 004. Ниже указан результат первого успешного прогона, а не последнего.

`go test ./tests/generator ./internal/generator ./internal/appserver -count=1` — PASS после добавления модульного API и сохранения исторического native850 через общий renderer. Адресный `go test ./tests/generator -count=1 -v` — 10 верхнеуровневых тестов, 13 отрицательных подслучаев; реальные пользовательские DIO-1/QUAL_STAT прочитаны, оба optional smoke выполнены без Skip.

- 32 инвертированных канала: 67 блоков, 66 связей, **один D32**, одна Quality/QUAL_STAT цепь, 34 карточки, 133 T11. Каждый `i00…i31` имеет один источник; `Ct0` не получает вымышленного входа.
- Второй модуль: собственный D32/Quality, сохранены пропуски `i01…i30`, прямой `i00` и инвертированный `i31`; одинаковый BOOL-тег делит карточку без смешения модулей.
- Синтетическая библиотека использует D32 ISA `91001` и QUAL_STAT `91002`: выход сохраняет их и имена библиотек, фиксированные native-ID не подставляются.
- Нет QUAL_STAT, противоречивые типы, нет ModuleID, повторный канал, CPU715 и legacy-профиль: отказ подготовки. HTTP-ошибка не меняет allocator и не создаёт файл; успех продвигает курсор ровно на рассчитанный диапазон и сохраняет один XML.
- Инверсия отдельного шаблона проверена дополнительно: +2 T11 на связь, без изменения исходного TemplateRef/карточек и без инверсии `sts`.

Проверки выполняются без импорта в SCADA; UI и итоговая упаковка проверяются основным пакетом 003. Принятый новый источник требований — предоставленный владельцем рисунок модульной схемы; аппаратный профиль/диалект сверены с существующим `DO_FBD_example.xml`. Отдельно требуется завершить физическую сепарацию исходников и тестов по пакету 004; этот отчёт не объявляет весь пакет 003 завершённым.
