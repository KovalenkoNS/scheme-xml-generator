# Инверсия FBD на связи сигнал → D32

Источник: уточнение владельца 29.09.2026 — «В FBD на связи сигнал - блок D32». Библиотека определяет типы, экземпляры и исходные связи; NOT — оператор подтверждённого XML-диалекта, а не замена библиотечного типа.

## Контракт

В `pous[].signals[]` используется необязательное `invert: boolean`, по умолчанию `false`. При `true` инвертируются только прямые связи библиотечного BOOL-сигнала с канальными входами `i00…i31` библиотечного D32V_v1. Связи диагностики `sts`, другие блоки, графика и карточки не меняются. Источник — BOOL-карточка с выходом `0`; неизвестные типы/порты не интерпретируются догадкой. Если такого пути нет или он неоднозначен/некорректен, запрос отклоняется до выдачи диапазона ID; подстановки нативного FBD-профиля нет.

NOT имеет подтверждённые `GROBJTYPE=35`, `ISAObjectID=-32`, `CI=1`, `CO=1`, вход `0`, выход `Result`, `cardId=0`, без `InitialValue`. Основание: неизменяемый экспорт [DO_FBD_example.xml](../../../tests/fixtures/generator/DO_FBD_example.xml) и его [описание](../../../docs/10-do-paz-native-semantics.md). Это правило оператора, не закрепление ID или сигнатуры D32 в программе. D32, BOOL, библиотека и ISA-номера берутся из выбранного шаблона.

Подтверждённый пример в пользовательской `all_lb_sinopec.xml`: OBJTYPE `2097/D32V`, TEMPLATE `12772/DIO-1`, исходный BOOL `1413309` → D32 `1413308.i00`, связь `1413310`. Полная пользовательская библиотека не включается в тестовый каталог; минимальный синтетический шаблон воспроизводит эту форму и меняет ISA-номера для проверки отсутствия подстановки.

При генерации создаётся копия выбранного шаблона в памяти, исходный `LoadedLibrary` не изменяется. Одна связь заменяется двумя с одним дополнительным NOT: расход T11 увеличивается на 2, расход карточек не меняется. Требования к диапазону вычисляются по этой же подготовленной копии; сериализация и проверка пользуются общим генератором. Геометрия расширяет шаблон вниз, не перекрывая его исходные примитивы.

## Проверка

- `invert=false` сохраняет исходную прямую связь без NOT.
- `invert=true` создаёт BOOL → NOT → D32.iNN; `sts` и другие связи остаются прежними.
- Смешанные инвертированные и обычные сигналы имеют непересекающиеся диапазоны и правильный расход ID/карточек.
- Исходная библиотека и входной запрос остаются равными своим снимкам.
- Отсутствие канального пути, неподтверждённый тип/порт, преобразование/выбор бита и повторное управление одним входом дают понятный отказ.
- Публичный HTTP API при отказе не создаёт XML и не меняет файл allocator.

Проверки подтверждают структуру XML; импорт и выполнение в SCADA отдельно не заявляются.
